# 踩坑与根因库（LESSONS）

> 目的：**同一个错误不犯第二次**。每条必须写清"现象 → 根因 → 修复 → 如何提前发现"。
> 新会话在做改动前应扫一遍本文，尤其是涉及数值、节点生命周期、UI 层级、打包时。

---

## L-001 · 数值系统整体失效：`int(速率 × delta)` 恒为 0
- **现象**：肉食恐龙喝水完全不回口渴、体力永不消耗（无限冲刺）、引导第 2 步永久卡死；45 秒口渴只降 2 点。
- **根因**：物理步长 1/60 秒，`int(45 × 1/60) = int(0.75) = 0`，逐帧累加永远加 0，且**不报任何错**。
- **修复**：改为 float 累加器，累满 1.0 才结算整数增减，余数保留（Vitals 已封装）。
- **提前发现**：任何"速率 × delta"的整数运算，一律检查小步长下的取整；单测必须模拟 60fps 跑 30-60 秒。

## L-002 · `global_position` 在节点入树前设置全部失效
- **现象**：headless 每棵树/岩石刷 `get_global_transform: !is_inside_tree()`，共 80 条；落点异常。
- **根因**：Godot 的 global 变换依赖父链，未入树时返回单位变换，赋值静默失败。
- **修复**：**先 `add_child` 再设 `global_position`**（WorldBuilder 全路径已改）。
- **提前发现**：冒烟日志里 grep `is_inside_tree` 必须为 0；新增生成代码统一"先入树后落位"。

## L-003 · 覆盖层忘记释放，残留叠在游戏画面上
- **现象**：选完地图后"选择地图/森林谷地/高山雪岭"一直叠在游戏里，还能误触重开选图。
- **根因**：`MapSelect` 只被局部变量持有，选中信号后从未 `queue_free`。
- **修复**：改成员引用，选中即释放；重开清理路径同步置空。
- **提前发现**：所有全屏覆盖层（选图/选种/加载/暂停/死亡/帮助）必须有明确生命周期所有者；冒烟里断言"游戏态只剩 HUD/触控/世界"。

## L-004 · 触摸层级吞掉 HUD 按钮
- **现象**：右上角「菜单」点不到，暂停菜单形同虚设。
- **根因**：HUD 与 TouchControls 同为 `CanvasLayer.layer=1`，触控层后入树且 LookZone `mouse_filter=STOP` + `accept_event()`，优先吞掉触摸。
- **修复**：HUD 层提到 2，除按钮外所有显示控件设 `MOUSE_FILTER_IGNORE`。
- **提前发现**：新增全屏触控区时，检查它与 UI 的 layer 顺序；真机点按所有可交互按钮做一遍。

## L-005 · MultiMesh 模板缓存的强类型数组误用
- **现象**：`Attempted to use 'has' an object of type 'Node3D' into a TypedArray` 6 条。
- **根因**：`Array[MeshInstance3D]` 上调用 `.has(root)`，而 root 是 Node3D。
- **修复**：改为 `if not (root is MeshInstance3D)`。
- **提前发现**：类型化数组只放同类型元素；对 Node 的"是否为某类型"判断用 `is`，不要用数组查找。

## L-006 · 横幅 tween 未 kill，旧回调杀掉新横幅
- **现象**：兽群/风暴/丰饶的事件提示永远看不到，被成就横幅顶掉后提前消失。
- **根因**：`show_banner` 每次新建 tween 不 kill 旧的；旧 tween 的 `visible=false` 回调在新横幅显示后触发。
- **修复**：保存 `_banner_tween` 并先 kill；成就横幅在事件横幅显示时排队延后。
- **提前发现**：所有"同一属性反复 tween"的地方都要缓存并 kill；UI 提示类必须做队列。

## L-007 · 暂停恢复后输入状态残留
- **现象**：暂停再继续，角色仍持续移动/叼尸。
- **根因**：暂停时 `button_up`/触摸抬起事件不派发，摇杆 `touch_index`、长按状态残留。
- **修复**：TouchControls 设 `PROCESS_MODE_ALWAYS`，检测暂停上升沿一次性复位所有输入电平并广播归零。
- **提前发现**：任何"按住型"输入都要考虑暂停/失焦/切后台的复位路径。

## L-008 · 子代理的结论不等于事实（终验必须独立验证）
- **现象**：审查报告把 `DinoVisual.glow()` 的 await 判为"会崩溃"（🔴），实际 Godot 协程随节点释放终止，不崩；另一份报告漏掉 MapSelect 未释放。
- **根因**：子代理基于静态阅读推断，缺少运行时证据；不同代理之间信息不共享。
- **修复**：建立"声明-验证"分离：子代理只提假设，主会话或终验代理必须用命令输出/测试数字确认；报告落盘时强制写验证方式。
- **提前发现**：所有 🔴 级结论必须附可复现命令与输出；无输出的一律降级为"存疑"。

## L-009 · 沙箱环境会被重置，工具链必须持久化
- **现象**：两次打包时 `/opt/android-sdk`、`/root` 下导出模板与 editor_settings 消失，导出报 "Invalid Android SDK path"。
- **根因**：只有 `/workspace` 持久；`/root`、`/opt` 属于易失层。
- **修复**：Godot/JDK/SDK/模板全部装到 `/workspace/tools`，用 `XDG_DATA_HOME`/`XDG_CONFIG_HOME` 指向持久目录；keystore 也放 `/workspace/tools`。
- **提前发现**：任何构建前先 `ls` 关键路径；构建脚本自带环境自检。

## L-010 · 减面/纹理压缩后必须重新导入再打包
- **现象**：资产替换后直接导出，包里仍是旧网格；`--editor --quit` 在缓存存在时只跑首轮扫描就退出。
- **根因**：Godot 依赖导入缓存，编辑器退出路径不保证处理完导入队列。
- **修复**：用 `--headless --import` 强制完成导入队列，再导出。
- **提前发现**：导出前核对 `.godot/imported` 文件数量与时间戳；导出日志出现 `_fs_changed` 且无产物即为导入未完成。

## L-011 · 存档双写会互相覆盖
- **现象**：进化时 PlayerDino 写盘只带 species/stage/generation，死亡时 Main 写盘带 best_time/best_kills；两边"读-改-写"交叉时字段丢失。
- **根因**：无单一写入权威，键名散落多个文件。
- **修复**：PlayerProfile + SaveRepository 单入口；Main 为死亡结算唯一权威；PlayerDino 进化写盘改"先读再写"。
- **提前发现**：任何持久化状态只能有一个写入口；新增字段先问"谁会覆盖它"。

## L-012 · 静态审查发现的"每帧全组遍历"会随人口线性恶化
- **现象**：AI 吃草/饮水每物理帧 `get_nodes_in_group` + 距离计算，30 AI × 60 植物 ≈ 每秒 10.8 万次开方；玩家每帧扫 AI 组算集群。
- **修复**：AI 感知收敛到 0.25s 决策周期并缓存目标；植物/水源缓存失效后等下一决策周期再刷新。
- **提前发现**：所有 `get_nodes_in_group` 必须问"调用频率"；> 4 次/秒的组查询需要缓存或空间索引。
